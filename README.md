# AXON — AI-агенты и автоматизация

Одностраничный статический сайт: чёрный фон, кольцо из GPU-частиц (three.js r150), которое «размешивается» курсором через жидкостную симуляцию, моноширинный интерфейс, 4 карточки-кейса с видео и колонка текста.

## Структура
- `index.html` — разметка и весь текст (бренд, чипы, карточки, колонка «что мы делаем / что автоматизируем / как работаем / связь»).
- `style.css` — цвета (`--accent #aa88ff` и др.), сетка, адаптив (≤1100 px, ≤760 px).
- `ui.js` — анимации интерфейса: появление со сдвигом, «расшифровка» заголовков, фильтр кейсов по чипам, пульс счётчика, курсор-точка. Учитывает `prefers-reduced-motion`.
- `main.js` — WebGL: частицы (512² = 262 144 точки, на мобильных 128² = 16 384), SDF-кольцо, curl-шум, жидкость от курсора, «взгляд» камеры, matcap генерируется в коде.
- `favicon.svg`, `og.png` — иконка и превью для соцсетей.
- `media/` — видео `case1–4.mp4` и постеры `case1–4.webp`.
- `.github/workflows/pages.yml`, `.nojekyll` — деплой на GitHub Pages.

## Что поменять
- **Контакты**: Telegram [@Dimoglov_official](https://t.me/Dimoglov_official) — ссылка в колонке «[связь]», кнопка «Обсудить задачу», JSON-LD и meta в `index.html`.
- **Карточки**: блоки `<article class="card" data-tags="…">` в `index.html` — видео `media/caseN.mp4`, подписи в `.meta`, темы для фильтра в `data-tags` (через запятую, как в чипах).
- **Чипы**: кнопки `<button class="chip" data-filter="…">` в `<nav class="tags">`; клик фильтрует карточки.
- **Счётчик** — число показанных кейсов, обновляется при фильтрации.
- Кольцо автоматически вписывается между левой колонкой и текстом (функция `fitRing` в `main.js`); форма — константа `K`, сила «размешивания» — `uMouseStrength` / `uMaxPush`, скорость «заживления» — `uHeal`.

## Видео
Бесплатные ролики Pexels (лицензия Pexels: можно использовать бесплатно, без указания автора), перекодированы в 640 px, без звука: ID 35008786, 34996641, 2887463, 40055307.

## Требования
Браузер с WebGL (лучше WebGL2). Если нет float-текстур — используется half float и меньше точек (до 256²); если нет ни того, ни другого — фон отключается, интерфейс работает. Сайт статический — открывайте через любой HTTP-сервер (`python3 -m http.server`), не через `file://`.

## Деплой на GitHub Pages
Залейте содержимое папки в корень репозитория (ветка `main`), в Settings → Pages выберите Source: **GitHub Actions** — workflow `pages.yml` опубликует сайт.

`og:image` указан относительным путём (`og.png`) — после публикации замените на полный URL сайта.
